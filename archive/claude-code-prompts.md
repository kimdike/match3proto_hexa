# 헥사 3매치 퍼즐 - 클로드 코드 작업 문서

## 📌 프로젝트 컨텍스트 (매 세션 시작 시 붙여넣기)

```
이 프로젝트는 헥사고날 3매치 퍼즐 게임이야.
기존에 1단계(헥사 그리드 77셀 렌더링)까지 완성됐어.
my-game 폴더에 index.html, style.css, game.js 파일이 있어.
기획서 내용은 아래와 같아:

- 그리드: 77셀, 9-8-9-8-9-8-9-8-9 벌집 구조
- 블록: 5/6/7가지 선택 가능, 무지개 7색
- 조작: 마우스로 블록 swap, 6방향 매치
- Move: 설정 가능, swap시 -1
- 점수: 블록 1개=100점, 3매치=300점, 4매치=500점, 5매치=800점
- 콤보 보너스: 2연쇄+500, 3연쇄+1000, 4연쇄+2000
- 목표: 20,000점 달성
- 블록 보충: 위에서 낙하
```

## 🤖 멀티에이전트 구조

클로드 코드는 복잡한 작업을 **여러 에이전트로 분담**시킬 수 있어.
아래처럼 역할을 나눠서 요청하면 효율적이야.

### 에이전트 1: 게임 로직 담당
```
너는 게임 로직 전담 에이전트야.
game.js 파일만 담당해.
UI나 스타일은 건드리지 마.

담당 작업:
- 헥사 그리드 좌표 계산
- 6방향 매치 감지 알고리즘
- 블록 swap 로직
- 콤보 시스템
- 점수 계산
- 블록 낙하 보충 로직
```

### 에이전트 2: UI/렌더링 담당
```
너는 UI/렌더링 전담 에이전트야.
index.html, style.css 파일만 담당해.
게임 로직은 건드리지 마.

담당 작업:
- 헥사 셀 시각적 렌더링
- 블록 색상 표시
- 점수판 UI
- move 카운터 UI
- 게임 시작/종료 화면
- 애니메이션 효과
```

### 에이전트 3: 테스트/디버깅 담당
```
너는 테스트/디버깅 전담 에이전트야.
코드를 수정하지 말고 문제점만 찾아서 보고해.

담당 작업:
- 에러 메시지 분석
- 버그 원인 파악
- 수정 방향 제안
```

## 📋 단계별 작업 프롬프트

### 2단계: 블록 색상 및 초기화
```
[컨텍스트 붙여넣기]

2단계 작업을 해줘.
game.js를 수정해서 각 셀에 랜덤 블록 색상을 배치해줘.
- 블록 종류: 5가지 (빨강, 주황, 노랑, 초록, 파랑)
- 처음부터 3매치가 없도록 초기 배치 해줘
- 각 블록은 data 속성으로 색상 정보를 가져야 해
```

### 3단계: 마우스 swap 조작
```
[컨텍스트 붙여넣기]

3단계 작업을 해줘.
마우스로 블록을 swap하는 조작을 구현해줘.
- 블록 클릭 → 선택됨 표시
- 인접한 블록 클릭 → swap 실행
- swap 후 move -1 처리
- 6방향 인접만 swap 가능
```

### 4단계: 매치 감지 및 제거
```
[컨텍스트 붙여넣기]

4단계 작업을 해줘.
6방향 3매치 감지 및 제거 로직을 구현해줘.
- swap 후 3매치 감지
- 매치 없으면 swap 되돌리기 (move 소모 없음)
- 매치된 블록 제거 + 점수 계산
- 점수: 3매치=300, 4매치=500, 5매치=800
```

### 5단계: 콤보 시스템
```
[컨텍스트 붙여넣기]

5단계 작업을 해줘.
연쇄 콤보 보너스 시스템을 구현해줘.
- 블록 제거 후 낙하 → 자동으로 새 매치 감지
- 2연쇄: +500점 보너스
- 3연쇄: +1000점 보너스
- 4연쇄 이상: +2000점 보너스
- 화면에 콤보 횟수 표시
```

### 6단계: 블록 낙하 보충
```
[컨텍스트 붙여넣기]

6단계 작업을 해줘.
블록 제거 후 위에서 새 블록이 떨어지는 로직을 구현해줘.
- 빈 칸은 위 블록들이 아래로 내려옴
- 맨 위 빈 칸은 새 랜덤 블록으로 채움
- 낙하 애니메이션 포함
```

### 7단계: UI 완성
```
[컨텍스트 붙여넣기]

7단계 작업을 해줘.
게임 UI를 완성해줘.
- 상단: 현재 점수 / 목표 점수(20000) 표시
- 상단: 남은 move 수 표시
- 시작 화면: 블록 종류(5/6/7) 선택 + move 수 설정
- 종료 화면: 클리어/실패 메시지 + 재시작 버튼
```

## 💡 팁
- 각 단계 완료 후 브라우저에서 F5로 확인
- 에러나면 F12 → Console 탭에서 에러 복사 후 클로드 코드에 붙여넣기
- 한 단계씩 완료 확인 후 다음 단계로 이동
