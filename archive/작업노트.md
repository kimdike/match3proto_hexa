## 📋 남은 작업 프롬프트

### 특수블록 교차 효과 9가지 구현
```
기획서.md와 game.js 읽고 특수블록 교차 효과 9가지 구현해줘.

현재 상태:
- sp1&&sp2 감지 로직은 있음
- 교차 효과 분기 없이 각각 개별 효과만 실행됨

구현 방식:
- activateCrossEffect(type1, type2, cell1, cell2) 함수 새로 만들어줘
- 두 특수블록 swap 시 개별 효과 대신 교차 효과 발동
- 모든 교차 효과는 동시에 처리 (순차 아님)

1. 줄볼 x 줄볼: 두 위치에서 동시에 각각 줄볼 효과 발동
2. 줄볼 x 폭탄볼: 줄볼 방향으로 3줄 동시 제거 (양옆 포함)
3. 폭탄볼 x 폭탄볼: 기준점 2칸 범위 총 19칸 동시 제거
4. 줄볼 x 타겟볼: 랜덤 위치로 날아간 후 해당 위치에서 줄볼 효과 발동
5. 타겟볼 x 타겟볼: 발사체 4개가 각각 랜덤 위치로 날아가 동시 제거
6. 폭탄볼 x 타겟볼: 랜덤 위치로 날아간 후 해당 위치에서 폭탄볼 효과 발동
7. 무지개볼 x 줄볼: 줄볼 색상 일반블록 모두 새 줄볼로 변환 후 동시 발동 (기존 줄볼 제외)
8. 무지개볼 x 폭탄볼: 폭탄볼 색상 일반블록 모두 새 폭탄볼로 변환 후 동시 발동 (기존 폭탄볼 제외)
9. 무지개볼 x 무지개볼: 퍼즐판 모든 블록 및 기믹 타격, isDestructible() 인터페이스로 확장성 고려
```

### 특수블록 생성 위치 로직 수정
```
기획서.md와 game.js 읽고 특수블록 생성 위치 로직 수정해줘.

올바른 규칙:
- swap으로 매치 발생 시:
  swap한 두 블록 중 매치 영역에 포함된 블록 위치에 생성 (드래그 방향 무관)
  두 블록 모두 매치 영역 안에 있으면 매치 영역 중앙에 가장 가까운 블록 위치
- 낙하로 인한 매치 발생 시:
  매치 영역 블록들 중 랜덤 위치에 생성

줄볼, 타겟볼, 폭탄볼, 무지개볼 모두 동일하게 적용해줘.
```

### 매칭 계산 속도 개선
```
기획서.md와 game.js 읽고 매칭 계산 속도를 개선해줘.

현재 문제: 매치 감지 → 제거 → 낙하를 순차적으로 처리해서 느림
개선 방향: 배치 처리 방식으로 변경
- 매치 감지 → 동시에 전체 처리 → 한번에 낙하 → 반복
- 연쇄 콤보도 빠르게 처리되도록 최적화
```

### 속도 조절 슬라이더 UI
```
기획서.md와 game.js, index.html, style.css 읽고
우측 UI에 속도 조절 슬라이더 2개 추가해줘.

1. 블록 낙하 속도 슬라이더
   - 범위: 0.5x ~ 3x
   - 숫자 직접 입력도 가능
   - 실시간 변경 즉시 반영

2. 타겟볼 날아가는 속도 슬라이더
   - 범위: 0.5x ~ 3x
   - 숫자 직접 입력도 가능
   - 실시간 변경 즉시 반영
```

### 실시간 매칭 (입력 버퍼링)
```
기획서.md와 game.js 읽고 실시간 매칭 시스템 구현해줘.

목표: 블록 낙하/연출 중에도 swap 조작 가능

조작 가능한 상황:
- 콤보 연쇄 중
- 블록 낙하 애니메이션 중
- 일반 특수블록 연출 중

조작 불가능한 상황:
- 무지개볼 사용 시
- 무지개볼 + 특수블록 교차 시

구현 방식: 입력 큐(Input Queue) 방식
- 조작 가능 상황에서 swap 시도 → 즉시 실행
- 조작 불가 상황에서 swap 시도 → 무시
```
